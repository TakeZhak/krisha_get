# Krisha.kz Parser MVP (CSV)

Простой MVP-скрапер для `krisha.kz` на `Python + Requests + BeautifulSoup`, который собирает:

1. `price` (цена)
2. `address` (адрес)
3. `area_m2` (площадь)
4. `author_name` (автор объявления)
5. `author_company` (компания автора, если указана)

И сохраняет результат в `CSV`.

По умолчанию CSV пишется с разделителем `;`, чтобы файл сразу корректно открывался в Excel (RU/KZ региональные настройки).

---

## 1) Что делает скрипт

Скрипт работает в 2 этапа:

1. Открывает страницы списка объявлений (каталог), собирает ссылки на карточки.
2. Заходит в каждую карточку и извлекает нужные поля, после чего пишет все строки в CSV.

```powershell

```

По умолчанию будет создан файл:

`krisha_listings.csv`

---

## 4) Полезные параметры запуска

```powershell
python parser.py --start-url "https://krisha.kz/prodazha/kvartiry/" --pages 3 --limit 100 --output "out.csv"
```

### Параметры

- `--start-url`  
  URL страницы поиска (можно с вашими фильтрами из браузера).

- `--pages`  
  Сколько страниц списка обходить.

- `--limit`  
  Лимит объявлений.  
  `0` = без лимита (парсить все найденные в заданных страницах).

- `--output`  
  Имя/путь итогового CSV.

- `--delay-min` и `--delay-max`  
  Случайная задержка между запросами, чтобы уменьшить риск блокировок.

Пример с более осторожной скоростью:

```powershell
python parser.py --pages 5 --limit 150 --delay-min 1.5 --delay-max 3.0 --output "krisha_safe.csv"
```

## 5) Формат CSV

Колонки:

- `url` — ссылка на объявление
- `price` — цена (целое число, без символа валюты)
- `address` — адрес/локация
- `area_m2` — площадь в квадратных метрах (float)
- `author_name` — имя автора
- `author_company` — компания (если указана, иначе пусто)

Пример строки:

```csv
url;price;address;area_m2;author_name;author_company
https://krisha.kz/a/show/123456789;19500000;"Астана, Есильский р-н, Улы Дала 86/1";35.1;"Верещак Руслан";"Vykup_i_prodazha"
```

## 6) Как скрипт извлекает ваши поля

- **Цена**: берется из блока цены на странице объявления.
- **Цена для коммерции**: если есть два значения (`за месяц` и `за м²`), в CSV записывается только основная цена (первое число).
- **Адрес**: берется из заголовка локации объявления.
- **Площадь**: ищется в параметрах объявления по метке "Площадь".
- **Автор**: берется из карточки владельца/специалиста.
- **Компания**: берется из блока компании владельца (если поле есть).
- **Очистка компании**: если в `author_company` попало значение из цифр/формата даты-времени, скрипт автоматически записывает `None`.

Если какой-то блок отсутствует на конкретной карточке, поле остается пустым.

## 7) Как пользоваться полностью пошагово

1. Откройте `krisha.kz` в браузере.
2. Настройте нужные фильтры (город, комнаты, цена и т.д.).
3. Скопируйте URL из адресной строки.
4. Запустите:

```powershell
python parser.py --start-url "ВСТАВЬТЕ_СКОПИРОВАННЫЙ_URL" --pages 3 --limit 100 --output "my_krisha.csv"
```

5. Дождитесь сообщения:
   - `[DONE] Saved N rows to my_krisha.csv`
6. Откройте `my_krisha.csv` в Excel/Google Sheets.

---

## 8) Важные ограничения

- Верстка сайта может меняться, тогда CSS-селекторы нужно будет обновить.
- Частые запросы могут вызывать блокировки или капчу.
- Компания автора присутствует не во всех объявлениях — это нормальная ситуация.
- Используйте парсер аккуратно: разумные задержки и ограниченное число запросов.

---

## 9) Диагностика проблем

### Ошибка `403/429/503`
- Увеличьте `--delay-min` / `--delay-max`
- Уменьшите `--pages` и `--limit`
- Повторите запуск позже

### Пустой CSV или мало строк
- Проверьте, что `--start-url` открывается в браузере без логина
- Увеличьте `--pages`
- Проверьте, не изменилась ли структура сайта

### Не найден `pip` или `python`
- Убедитесь, что Python установлен и добавлен в PATH
- На Windows можно попробовать `py parser.py`
