# Krisha Parser Web (Vercel)

Веб-приложение для парсинга `krisha.kz` с кнопкой скачивания Excel-совместимого CSV.

Собираемые поля:
- `url`
- `price`
- `address`
- `area_m2`
- `author_name`
- `author_company`

CSV отдается с разделителем `;`, поэтому в Excel открывается сразу по колонкам.

## 1) Локальный запуск

```powershell
npm install
npm run dev
```

Открой: `http://localhost:3000`

## 2) Как пользоваться сайтом

1. Вставь ссылку поиска с `krisha.kz` (квартиры или коммерция).
2. Укажи:
   - сколько страниц обходить;
   - лимит объявлений (`0` = без лимита);
   - задержки между запросами.
3. Нажми **"Загрузить в Excel (CSV)"**.
4. Браузер скачает `.csv` файл.

## 3) Деплой в Vercel

1. Залей проект в GitHub.
2. В Vercel: **New Project** -> выбери репозиторий.
3. Framework: `Next.js` (определится автоматически).
4. Нажми **Deploy**.

Никакие переменные окружения для базового запуска не нужны.

## 4) Логика парсинга

API-роут: `app/api/scrape/route.ts`

Что делает:
1. Получает параметры из формы.
2. Проходит страницы списка объявлений.
3. Заходит в карточки объявлений.
4. Извлекает поля.
5. Возвращает CSV как файл для скачивания.

Особенности:
- для коммерции, где у цены два значения (`за месяц` и `за м²`), берется первое (основная цена);
- если `author_company` выглядит как дата/цифровой мусор, записывается `None`;
- если компания не указана, поле пустое.

## 5) Ограничения

- На больших объемах возможны капча/блокировки.
- Увеличивай задержки, если появляются ошибки.
- Сильные изменения верстки `krisha.kz` потребуют обновления селекторов.
